# SilkWarp

面向自建家宽服务器的轻量级低延迟远程桌面与串流方案（团队内部使用），目标是实现类似网易 UU 远程的流畅不卡体验与常用远控能力。

## 核心目标

- **高画质低延迟串流**：基于硬件编解码（NVENC / AMF / QSV）实现高帧率、低延迟桌面与图形画面传输
- **家宽公网 / P2P 穿透与中继兜底**：优先 P2P 直连（含 IPv6 / 打洞），复杂 NAT 环境下支持自建中继服务兜底
- **多端统一接入**：支持 Windows / macOS / Android / iOS 等常见终端接入
- **完整远控与办公能力**：无人值守开机自启、锁屏与 UAC 操作、虚拟显示器、隐私屏、剪贴板同步、文件传输与远程开机（WOL）
